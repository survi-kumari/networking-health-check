# Networking Health Check

## Project Overview
This project is a Bash script that checks basic network
configuration and connectivity on a Linux system.

## Features
- Displays network interfaces and IP addresses
- Displays the routing table and default route
- Checks DNS resolution
- Tests HTTPS connectivity
- Displays listening TCP and UDP ports

## Requirements
- Linux or Ubuntu (WSL)
- Bash
- iproute2
- curl (optional for HTTPS check)

## How to Run

Make the script executable:

    chmod +x network_check.sh

Run the script:

    ./network_check.sh

## Technologies
- Linux
- Bash scripting
- Networking commands
